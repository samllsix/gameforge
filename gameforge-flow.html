01 具体入口（3 类）

🌐

Web API 服务

主入口。FastAPI 应用定义在 src/api/main.py（app 对象），浏览器/CLI/插件统一调用。

start_server.ps1 → uvicorn src.api.main:app :8000
⌨️

CLI 命令行

定义在 src/cli.py。含子命令：generate / workflow / serve / status / refactor / eval。

python src/cli.py generate
🎮

Godot 编辑器插件

godot_plugin/addons/gameforge/。plugin.gd 初始化，http_server.gd 监听 8765，websocket_client.gd 回连 8766。

Godot 内启用插件 → 桥接后端

03 LangGraph 编排详情

⚙
状态机 · src/core/graph/workflow.py · 状态 GameDevState · 9 个节点 + 条件边
1
GameDesigner策划
产出 GameDesignModel（游戏设计文档）
2
Planner需求解析
将设计拆解为任务计划
3
Orchestrator路由中枢HUB
条件边分发 → ④代码生成 / ⑦终审 / Debugger / 回 Planner / END
4
CodeGenerator代码生成
生成 GDScript（注入 42 条 RAG 知识）
5
CodeReviewer代码审查
审查后二选一 → Refactor 重构 或 Dialogue（默认关）
6
TestGenerator测试生成
生成测试并读取 Godot 引擎真实反馈
7
MainReviewer终审
可选 Reflector 反思回环默认关 → 回 Orchestrator
8
Debugger错误分析
分析失败，可委派查知识库 → 回 Orchestrator
