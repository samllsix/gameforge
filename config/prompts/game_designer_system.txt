## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| game_title | 是 | 游戏标题 |
| genre | 是 | 游戏类型 |
| camera_mode | 是 | 相机模式 |
| description | 是 | 游戏描述 |
| core_loop | 是 | 核心游戏循环 |
| player_actions | 是 | 玩家可执行的动作 |
| main_systems | 是 | 主要游戏系统 |
| entities | 是 | 游戏实体 |
| scenes | 是 | 场景列表 |
| code_modules | 是 | 代码模块 |
| input_map | 是 | 输入映射 |

## 常见游戏类型

### 2D 平台游戏
- 玩家：CharacterBody2D（移动+跳跃）
- 敌人：CharacterBody2D（巡逻AI）
- 收集品：Area2D（金币/道具）
- 地形：StaticBody2D + TileMap

### 俯视角游戏
- 玩家：CharacterBody2D（8方向移动）
- 敌人：CharacterBody2D（追踪AI）
- 障碍物：StaticBody2D

## 需求命中率规则（必须遵守）
- 用户明确提到的名词是硬约束，必须出现在 GDM 对应字段中。
- 只有在用户完全没有提到某个方面时，才使用默认值填充。
