三、P0-1 需求与产物完全脱节（核心阻断缺陷）

P0无论提交什么需求，产物永远是同一个"海洋主题平台跳跃游戏"。两轮独立测试均复现。

  • 美术指导器按 "深海 珊瑚 沉船" 主题包生成全部生图提示词——与"太空"需求毫无关系：

四、P0-2 多智能体工作流空转

P07 个 Agent 进度条全部 100%，但对最终可玩产物贡献为零。

  • GDM 贫瘠且无质量门禁：game_designer 的 LLM 返回缺失 game_title、entities/main_systems 为空，校验条件 any(k in gdm for k in ("game_title","genre","core_loop","entities")) 过宽——只要含 genre 即放行，缺字段由 normalize 填默认值「未命名游戏」；
  • 规划塌缩：planner 基于贫瘠 GDM 只生成 1 个任务（task_plan_generated_from_gdm task_count=1），代码生成最终产出 0 个 .gd 脚本（gd_guard 扫描结果 {'gd': 0, 'tscn': 1, 'project_godot': 1}）；
  • 门禁形同虚设：baseline_checker 15 项检查通过、gd_guard 放行——因为检查的是预览兜底写的模板项目，而非工作流产物；
  • 两轮均复现，非偶发。

五、P1 缺陷

P1-3并发重复生成，成本放大 ~11 倍

250ms 高频轮询下，多个并发 /preview/frame 请求同时发现 main.tscn 缺失，各自触发完整的资产管线（AI 生图 11 张 + SFX 5 段 + BGM）。单项目锁未覆盖生成全程：

19:42:29 asset_forge.done  ×7   ← 同一秒 7 个并发构建全部完成全套资产生成
19:42:29 sfx_forge.done   ×7
19:42:29 preview.scene_auto_generated ×7
19:42:32/43/46, 19:43:33 …  ← 后续又有 4 轮，累计 ~11 次完整生成
修复方向：auto-build 前先抢"项目级互斥标记"（内存锁 + 磁盘 sentinel），后续轮询请求等待或复用，而不是各自全量生成。按单次管线 11 图 × ~15s 估算，本轮浪费约 10 次生图调用。

P1-4Godot 预览进程崩溃循环 + 端口分配竞态

  • 预览每 15–20s 出现一次「HTTP 502 → 降级模拟 → 重连」震荡；supervisor 因 health_status_502 反复重启进程（日志中同一项目 spawn 10+ 次）；
  • 端口竞态：_pick_free_port 从 8769 起探测空闲端口，进程退出后端口被释放，另一项目立即抢占——第 1 轮观测到 demo_jump_v2 与 GameForge_Project 同时被分配到 8770，互相冲突崩溃；
  • UI 未构建时默认轮询旧项目 demo_jump_v2，制造无关负载与第二个冲突源。
修复方向：① 端口按 project_id 确定性分配（或维护 port→project 注册表，重启复用原端口）；② health_fail 连续 N 次再重启（当前 consecutive=1 即重启）；③ 预览兜底项目与 UI 默认轮询目标收敛为当前会话项目。

P1-5Web 导出被发布门禁拦截，无法出包

导出 API 实测返回 release_gate_failed，两类错误：

ERROR: …scenes/main.tscn'. at: instantiate (scene/resources/packed_scene.cpp:211)   ← 场景实例化失败
ERROR: [screenshot_server] listen failed on 127.0.0.1:8769 err=22               ← 冒烟实例与常驻预览抢同一端口
修复方向：runtime_smoke 启动 Godot 时注入独立 GAMEFORGE_PREVIEW_PORT（或临时移除 screenshot_server autoload），与常驻预览进程隔离；排查 headless 冒烟下场景实例化失败的具体资源依赖。

六、P2 缺陷与观察

  • P2-6同项目重提交新需求不触发重生成：asset_forge 幂等复用 + 场景已存在 → 第 1 轮（复用目录）中，太空射击需求完全复用了旧"深海"产物（资产时间戳停在 16:09–16:10，main.tscn 未更新）。需求变更应使资产缓存失效；
  • P2-7MusicGen 加载曾致服务进程崩溃：首轮服务在 audio_engine.loading backend=musicgen 后进程级崩溃（exit code 1）。Python 层 fallback 无法兜住原生库段错误，音频模型加载应移出 API 进程（子进程/独立服务）；
  • P2-8UI 预览 fps 显示 1157/1255：降级模拟模式下的假帧率，与真实渲染状态混淆，建议区分 LIVE/SIM 标识下的数据来源；
  • P2-9art_director 兜底先于 LLM 计划执行：fallback_plan（ocean）先行落日志多次后才出现 llm_plan，轮询路径重复规划。
