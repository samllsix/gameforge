00方案摘要

一段话说清这次美化在做什么、不做什么。

做的三件事：

① 重建字号与对比度体系——当前 7.5~10px 的正文是全球可读性硬伤，全部按新 token 提升一档，辅助文字对比度从 ≈3.6:1 修到 ≥4.5:1。

② 建立"光效预算"——发光只保留给三种东西：状态指示（LIVE 灯、活动阶段）、交互反馈（hover/focus）、以及星系本体。静态内容一律去光，让星系重新成为唯一主角。

③ 放大核心任务路径——命令栏与实时预览是这套工具的命脉：输入区强化为不可忽视的主操作，预览区扩大近一倍并补全 LIVE/SIM/IDLE 状态语义。

不做的三件事：

不改配色世界观（青×紫全息是资产，保留）；不动信息架构与后端联动逻辑（SSE / 预览轮询 / 空闲停机全部原样）；不重写布局骨架（CSS Grid 结构保留，只调尺寸）。

按严重度排序的问题清单

P0字号体系崩溃，正文 7.5~10px
日志 8.5px、进程项副标 7.5px、面板标题 11.5px——长期盯屏的工具型产品用这个字号，等于让用户自带放大镜工作。
建立 6 档字号 token（10/11/12.5/13.5/15/20px），最小可读字号 11px，装饰性英文角标允许 10px。全局替换约 60 处字号声明。
P0视觉层级缺失：全屏发光，无处落眼
每块面板都有扫描线 + beam 扫光 + 双层 box-shadow 辉光 + 内发光，标题带 text-shadow，四角卡片还在呼吸发光。注意力被均摊，等于没有注意力。
实施"光效三级预算"（见 §03），beam 只保留 header 一处，glowPulse 呼吸动画整体移除，静态文字全部去 text-shadow。
P1对比度不达 WCAG AA
--muted #7e93b8 在面板底色上约 3.6:1（AA 要求 4.5:1），日志正文 #9fc6e8 8.5px 双重打折；h-center 标题的 22px 辉光 text-shadow 进一步糊掉字形。
--muted 提亮至 #8fa5c9（≈4.7:1），日志正文提至 #b7d4ee + 11px；标题 text-shadow 从三图层减到一层窄半径。
P1快速模板卡片表达力弱
6 张卡只有色块渐变 + 中心白点 + 9.5px 文字，品类识别全靠读字；hover 只有位移没有信息增量。
每卡增加品类线性 SVG 图标（统一 1.5px stroke 语言），标签升至 12px，hover 时浮出一句玩法描述副标（如"收集金币 · 躲避敌人"）。
P1实时预览区小到无法判断画面
预览盒仅 74px 高，Godot 真渲染的画面在这个尺寸下只剩色块，LIVE 标签失去了它想传达的"真的在跑"的说服力。
预览盒升至 140px（占右侧栏约 1/3 高），增加角标状态胶囊化（LIVE=青色实底 / SIM=琥珀描边 / IDLE=灰），右上角加"⤢ 全屏"按钮点击放大为中央浮层。
P2无障碍与响应式空缺
无 prefers-reduced-motion（星系旋转、beam、卡片漂浮全部常开，前庭敏感用户无法关闭）；交互元素无 :focus-visible；overflow:hidden + 固定三栏，1366px 以下笔记本已经拥挤。
加 reduced-motion 媒体查询（动画归零、星系渲染单帧）；全局 focus-visible 描边；补充 1400/1100/820px 三档断点策略（见 §05）。
P3一致性杂项
双标题冗余（左上 GameForge + 中央 Gameforge-数字生命系统）；能量核心两处数值不一致（仪表盘 71% vs 文本 72%）；🎲 emoji 与科幻线性图标混搭；energyCanvas 处于 display:none 但渲染循环每帧仍在绘制（纯性能浪费）；滚动条样式定义了两遍。
标题合一；两处数值统一从同一变量取值；emoji 换 SVG 骰子；从 loop() 移除 drawEnergy 或删除该 canvas；滚动条样式收敛为一个 utility 选择器组。

02设计方向

「一收一放」：放大星系与命令栏，收起其余一切装饰。

现有界面的世界观不需要推翻——全息、深空、青紫双辉光是这套产品的性格。问题在于所有元素都在用同样的音量喊话。新方向借鉴航空航天控制室的逻辑：仪表台本身是安静的、克制的、可读的，唯一的"奇观"留给中央那台仪器——星系全息投影。

具体执行为三个动作：

① 放（Hero 强化）——星系保持现有 WebGL 渲染不动，四角卡片后退（更透明、更小、去呼吸动画），让星系核心的视觉统治力恢复；命令栏升格为最醒目的操作件，预览区扩容。

② 收（仪表降噪）——所有侧栏/底栏面板去掉 scanline、beam、多层辉光，只留细边框 + 微弱内高光，像真实仪器面板的哑光质感；发光成为"信号"而非"装修"。

③ 统（语言归一）——图标全面 SVG 线性化（统一 stroke 1.5px），文字层次用字号/字重区分而非发光强度，等宽字体只用于数字与日志。

两张概念图由 Seedream 生成，用于传达"密度、留白、光效配比"的方向感；图内文字不可作为文案依据，最终实现以本方案的代码规格为准。

03设计系统升级

四组 token 直接进 :root，后续所有模块改造都引用这里。

3.1 字号阶梯（Type Scale）

--fs-microMICRO 10px · 装饰英文角标替代原 7.5px
--fs-captionCAPTION 11px · 时间戳/辅助说明替代原 8~8.5px
--fs-bodyBODY 12.5px · 正文/日志/标签替代原 9~10px
--fs-subSUB 13.5px · 列表标题/按钮替代原 10.5~12px
--fs-titleTITLE 15px · 面板标题替代原 11.5px
--fs-heroHERO 20px · 页面主标题维持量级

3.2 色彩令牌（含对比度修正）

--text-1#eaf3ff 主文本 15.8:1
--text-2#c0d0e8 次级 ≈11:1
--text-3#8fa5c9 辅助 ≈4.7:1 ↑
--cyan#43e6ff 交互/状态
--violet#a06bff 次强调
--good#36e0aa 成功/在线
--warn#ffb454 警告/SIM
--err#ff5d6c 错误

核心变化只有一个：--muted:#7e93b8 → --text-3:#8fa5c9，一次性修复全部辅助文字的对比度。语义色与背景色体系维持不变。

3.3 光效三级预算（Glow Budget）

L0 · 信号光（常亮）

仅限状态语义：LIVE 指示灯、当前活动阶段进度条、ECG 波形、星系本体。预算 8~12 处。

L1 · 反馈光（瞬时）

仅出现在交互瞬间：hover 边框增亮、按钮按下、focus 描边、构建成功的一次性庆祝脉冲。离场即灭。

L2 · 静默（零光）

一切静态内容：面板容器、正文文字、静态图标、分隔线。无 box-shadow 辉光、无 text-shadow。

3.4 间距与形状令牌

/* 新增 spacing/radius 令牌 */
:root{
  --sp-1:4px;  --sp-2:8px;  --sp-3:12px;  --sp-4:16px;
  --r-panel:10px;   /* 面板统一圆角（原 12px 略收紧） */
  --r-ctrl:8px;    /* 控件圆角 */
  --gap:14px;        /* 栅格间隙 12→14px，缓解密度 */
  --edge:rgba(96,180,255,.22);  /* 边框微调亮，补偿去辉光后的层次 */
}

补偿策略：面板去掉辉光后容易"变平"，用更清晰的边框（--edge 提亮）+ 顶部 1px 内高光 + 更深的投影维持立体感——这是真实航空仪表的做法：哑光机身 + 精密刻线。

05动效与无障碍

把"看起来高级"变成"谁都能用"。

5.1 Reduced Motion

当前全站 7 类无限循环动画（星系旋转、beam、卡片漂浮/呼吸、pulse、flowShift、背景粒子、ECG）没有任何关闭手段。方案：CSS 动画在媒体查询内归零；JS 主循环检测 matchMedia('(prefers-reduced-motion: reduce)')，命中时星系只在挂载时渲染单帧、粒子背景静止。

@media (prefers-reduced-motion: reduce){
  .beam,.fcard,.flow-wrap::after,.sysstat .ok i{animation:none!important}
  .nav-item,.qt .t,.cmdbar button{transition-duration:.01s}
}
/* JS */
const RM = matchMedia('(prefers-reduced-motion: reduce)').matches;
if(RM){ drawGalaxy(0); /* 渲染单帧后不再进入 rAF 星系循环 */ }

5.2 键盘与焦点

全局补 :focus-visible（2px var(--cyan) 描边 + 2px offset），覆盖命令输入、两个按钮、9 个导航项、6 张模板卡；命令输入绑定 Ctrl+Enter 提交；骰子/全屏等图标按钮补 aria-label。
